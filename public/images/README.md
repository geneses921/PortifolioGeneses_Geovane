# 📸 Foto de perfil

Coloque aqui sua foto profissional com o nome **`profile.jpg`**.

Caminho final esperado:

```
public/images/profile.jpg
```

## Recomendações

- Formato: JPG ou PNG
- Proporção: 1:1 (quadrada) — a foto é exibida em um container circular
- Resolução mínima: 600×600 px
- Peso recomendado: até 500 KB

> Enquanto o arquivo não existir, a área da foto exibe um placeholder elegante com a mensagem "Sua foto aqui".
