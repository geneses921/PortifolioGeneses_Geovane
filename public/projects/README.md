# 🖼️ Imagens dos projetos

Coloque aqui as imagens de capa dos seus projetos.

Caminhos utilizados no array `projects` em `data/projects.ts`:

```
public/projects/projeto-1.png
public/projects/projeto-2.png
public/projects/projeto-3.png
public/projects/projeto-4.png
```

## Recomendações

- Formato: PNG ou JPG
- Proporção: 16:9 (ex: 1280×720) — o card usa `aspect-video`
- Resolução mínima: 1280×720 px
- Peso recomendado: até 300 KB por imagem

> Se o caminho da imagem não existir, o card exibe automaticamente um placeholder gerado com gradiente e o nome do projeto.
